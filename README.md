# Hospital Management System

A Full Stack Hospital Management System built using Spring Boot, React, MySQL, and JWT Authentication.

## Features
- Patient Management
- Doctor Management
- Appointment Scheduling
- Billing Management
- Laboratory Management
- Pharmacy Management
- JWT Authentication
- Role-Based Access Control

## Tech Stack

### Frontend
- React.js
- React Router
- Axios
- CSS

### Backend
- Spring Boot
- Spring Security
- JWT Authentication
- Hibernate/JPA

### Database
- MySQL

## System Architecture
Frontend → Spring Boot REST API → MySQL Database

## Installation

### Backend
cd backend
mvn spring-boot:run

### Frontend
cd frontend
npm install
npm run dev
